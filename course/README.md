# Каркас курса OOPoman

Откройте `index.html` непосредственно в Google Chrome. Страница использует только локальные HTML, CSS, JavaScript и хранилище браузера. Сервер, вход, установка пакетов и сеть не нужны.

Первая неделя открыта, недели 2 и 3 закрыты. Названия лекций и лабораторных указаны для сопоставления с исходными файлами; содержимое PDF не копируется, заданий в этом каркасе нет. Открытие лабораторной первой недели записывает отметку `started`. Завершение и баллы недоступны, пока нет настоящих заданий.

Прогресс хранится в ключе `oopoman.progress.v1` профиля браузера. Подтверждённый сброс удаляет только этот ключ. Не очищайте всё хранилище браузера ради сброса курса.

Для повторного запуска используйте тот же профиль Chrome и не перемещайте папку курса. Политика браузера или запрет хранилища могут помешать сохранению; интерфейс покажет ошибку вместо заявления, что отметка записана.
